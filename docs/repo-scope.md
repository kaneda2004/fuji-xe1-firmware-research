# Repository Layout

This repository is organized around notes, helpers, and small probe scripts
that make the X-E1 firmware research easier to reproduce.

- `docs/` records the file format, loader settings, offsets, and findings.
- `tools/` contains original analysis helpers.
- `probes/` contains AUTO_ACT scripts used for small behavior checks.
- `samples/` contains metadata examples for expected tool output.

Generated outputs stay in local working directories and are covered by the
repo `.gitignore`.
